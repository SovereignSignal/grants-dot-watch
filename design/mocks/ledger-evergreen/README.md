# The Ledger, evergreen

Approved mockups for the grants.watch redesign, September 24, 2026. The spec is
[docs/REDESIGN.md](../../../docs/REDESIGN.md).

- `front-page.png` / `.html`: the front page at desktop width
- `front-page-mobile.png` / `.html`: the front page on a phone
- `program-page.png` / `.html`: a program page, using Rocket Pool

The HTML files open in any browser and carry the exact colors, sizes and spacing as inline
styles. Counts are sample values from the registry on September 24. The build computes them
live.
